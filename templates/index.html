How the CNN Pipeline Works

1. Preprocess

Grayscale conversion, thresholding, and dilation prepare handwriting structure for model input.

2. Feature Extraction

Convolution + pooling layers detect stroke patterns and texture signatures from script flow.

3. Classification

Dense layers classify emotion tendencies into Calm, Stressed, Angry, and Focused.

4. Output Visualization

API response is shown with confidence bars for clear interpretability during demos and viva.
